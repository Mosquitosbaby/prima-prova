# prima-prova  
Scrivi un programma in linguaggio C che richieda all'utente di inserire quattro numeri interi. Il programma deve eseguire le seguenti verifiche utilizzando gli operatori logici:
Verificare se tutti i numeri sono compresi tra 1 e 50 (inclusi) utilizzando l'operatore and.
Verificare se almeno uno dei numeri è un multiplo di 5 utilizzando or.
Verificare se nessuno dei numeri è negativo utilizzando l'operatore  not.
Verificare se esattamente due dei numeri sono pari.
